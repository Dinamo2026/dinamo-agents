# dinamo-agents

דף פרטי של מועדון הרכיבה דינמו. **כל התוכן בדף מוצפן** (AES-GCM, מפתח נגזר
מסיסמה ב-PBKDF2) ונפתח רק בדפדפן של מי שיודע/ת את הסיסמה. אין כאן מידע קריא.

הריפו ציבורי רק כדי ש-GitHub Pages יוכל להגיש את הדף בחינם.

## לבנות מחדש

```bash
python3 build.py "<הסיסמה>"
```

`src/agents.json` = נתוני הסוכנים · `src/shell.html` = הדף (עם `__CIPHER__` כתחליף).
הבנייה מצפינה את הנתונים ומזריקה אותם ל-`index.html`.
**המקור נשמר כאן בכוונה** — בלעדיו כל שינוי דורש לפענח את הדף החי.
